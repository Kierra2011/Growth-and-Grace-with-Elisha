# 🌱 Growth and Grace with Elisha

A modern, responsive web application designed as a safe, gentle space to express your feelings and reflect on your daily emotional well-being. Built with pure HTML, CSS, and JavaScript.

Live Website: [https://kierra2011.github.io/grace-growth/](https://kierra2011.github.io/grace-growth/)

---

## ✨ Key Features

* 🤖 **Empathetic Chatbot Companion:** Talk to Elisha, a companion tuned to respond thoughtfully to expressions of sadness, anxiety, joy, or frustration.
* 👤 **Customizable Experience:** Optional name input on entry, allowing Elisha to personalize conversations—or continue anonymously without needing an email address.
* 🌙 **Light & Dark Mode:** Toggle seamlessly between clean light and dark themes for comfortable daytime or night-time use.
* 📱 **Mobile-First Responsive Design:** Optimized for all screen sizes (iOS & Android) with touch-friendly controls and dynamic viewport heights.
* 🎨 **Integrated SVG Logo:** Clean vector branding built directly into the codebase with no external image dependencies.

---

## 🛠️ Built With

* **HTML5** – Semantic structure & inline SVG graphics
* **CSS3** – Custom properties (variables) for theme switching & flexbox layout
* **JavaScript (ES6)** – DOM manipulation, state management & emotion recognition logic
