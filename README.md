# Grace & Growth with Elisha 🌿

**Grace & Growth with Elisha** is a beautiful, highly polished, and gender-neutral daily self-care workspace engineered to counteract procrastination, rebuild self-esteem, and chart personal evolution through intentional design. 

Built entirely with clean, vanilla web technologies, the app uses a grounded earth-tone canvas that dynamically responds to focus modes while keeping data fully private by saving your metrics locally in your own browser.

---

## ✨ Core Architecture Features

* **Daily Tasks & Momentum Monitor:** Log tiny, actionable tasks and visualize your immediate progress with a fluid, real-time completion percentage.
* **Reflective Navigation Mapping:** Features a tab-oriented interface divided into an execution workspace (**Home**) and an emotional offloading space (**Journal**).
* **Adaptive Earth-Tone Framework:** A soft, glowing warm nude/beige canvas for Light Mode that gracefully transitions into a deep forest charcoal canvas accented by warm gold signatures for Dark Mode.
* **Dynamic Low-Load Marquee:** A customized, slow-moving continuous ticker banner running at a comfortable reading pace featuring words of encouragement, positive behavioral prompts, and biblical scripture focus nodes.
* **Interactive Gratitude Sandbox:** Integrated inspiration prompt generator specifically designed to break toxic rumination patterns and save persistent reflection logs.
* **Gamified Checking Verification:** Automated daily logging mechanics that track consecutive activity streaks without relying on external databases.

---

## 🛠️ Technology Ecosystem

The codebase operates with zero heavy dependencies or framework bloat, making it highly responsive and optimized for instant loading:

* **HTML5:** Modern structural framework layout utilizing semantic web components (such as `<main>`, `<section>`, and `<nav>`) rather than unstructured container blocks.
* **CSS3:** Custom animation scroll drivers, grid/flex variable scopes (`:root` / `[data-theme="dark"]`), and smooth micro-shadow typography treatments.
* **JavaScript (ES6):** Pure, modern script standards utilizing Arrow functions (`=>`), template literals, local arrays, object destructuring, variable scoping (`let`/`const`), and standard browser lifecycle mapping.

## 🚀 Rapid Deployment Layout

### Running Locally
1. Clone the repository framework to your device:
   ```bash
   git clone https://github.com
   ```
2. Navigate into the main repository directory:
   ```bash
   cd grace-and-growth
   ```
3. Open `index.html` directly in any updated desktop or mobile browser environment.

### Hosting on GitHub Pages
1. Push this repository layout directly up to your GitHub profile.
2. Navigate to your repository settings page (**Settings**).
3. Select the **Pages** sidebar segment from the settings checklist.
4. Set the build source framework to target the **Main** branch, then click save. 
5. Your platform will be hosted live on the web automatically via a custom secure URL.

---

## 🔒 Privacy Architecture
This web tool does not contain hidden telemetry, analytical tracking scripts, or cloud servers. All personal tasks, logged entries, and streak counters are preserved entirely within your web browser's local sandbox memory (`localStorage`). Clearing your browser cookies or storage variables will refresh the workspace state.
